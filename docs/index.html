eNoVA-Editor

Der eNoVA-Editor ermöglicht Kommunen, Dateien im Format XJustiz.enova.2900003 in einer menschenlesbaren Form anzuzeigen und eine XJustiz-Antwortdatei zu erstellen.

Quellcode auf GitHub Dokumentation des Formats
Ab Januar 2027 sind Kommunen in Deutschland verpflichtet, Vorkaufsrechtsanfragen von Notaren digital im Format XJustiz.enova.2900003 zu bearbeiten.

Über das Projekt

Die Landeshauptstadt München entwickelt federführend den eNoVA-Editor für alle Kommunen in Deutschland. Sie stellt das Tool als Open-Source-Software kostenlos unter der MIT-Lizenz zur Verfügung.

Das Projekt befindet sich derzeit in der Testphase. Diese wird voraussichtlich am 1. Dezember 2026 abgeschlossen.

Was macht der eNoVA-Editor?

Nach Eingang einer Nachricht über das beBPo öffnen Sachbearbeiter*innen die XML-Datei im eNoVA-Editor. Die für die Bearbeitung relevanten Inhalte werden in Briefform übersichtlich dargestellt.

Anschließend können sie Aktenzeichen, Sachbearbeiter*in und Entscheidung erfassen und daraus eine rechtskonforme XJustiz-Antwortdatei erstellen.

eNoVA Editor

The eNoVA Editor enables German municipalities to display XJustiz.enova.2900003 files in a human-readable format and create an XJustiz response file.

Source code on GitHub Format documentation
Starting in January 2027, municipalities in Germany are required to process pre-emption right requests from notaries digitally in the XJustiz.enova.2900003 format.

About the project

The City of Munich is leading the development of the eNoVA Editor for municipalities throughout Germany. The tool is made available free of charge as open-source software under the MIT License.

The project is currently in the testing phase, which is expected to be completed by 1 December 2026.

What does the eNoVA Editor do?

After receiving a message via the beBPo secure government mailbox, caseworkers open the XML file in the editor. The information relevant to processing the request is displayed in a clear, structured format.

They can then enter the file reference, select the responsible caseworker and record a decision to generate a legally compliant XJustiz response file.
