Häufig gestellte Fragen (FAQ)

Welche XJustiz-Nachrichten unterstützt der eNoVA-Editor?

Der eNoVA-Editor unterstützt ausschließlich das Format eNoVA.2900003. Er verarbeitet eingehende Nachrichten vom Typ ersuchenSachentscheidung und erstellt daraus Antwortnachrichten vom Typ sachentscheidung.

Kann eine Behörde selbst eine Anfrage an einen Notar erstellen?

Nein. Beim Format eNoVA.2900003 wird die Kommunikation immer durch eine Anfrage des Notars eingeleitet. Die Behörde kann darauf mit einer Sachentscheidung antworten, aber keine eigene initiale Anfrage erstellen.

Muss die Antwort der Behörde als PDF erstellt werden?

Nein. Die XML-Datei selbst stellt den Bescheid dar. Ein zusätzliches PDF ist bei eNoVA.2900003 nicht vorgesehen. Die XML-Antwort muss entsprechend signiert werden.

Wie muss die Antwort der Behörde signiert werden?

Die Antwort benötigt eine Signatur mit Organisationsvalidierung. Dadurch kann die empfangende Stelle überprüfen, ob der Bescheid tatsächlich von der zuständigen Behörde stammt. Eine gewöhnliche persönliche Signatur oder ein Siegel reicht dafür nicht aus.

Kann es passieren, dass eine Signatur beim Versand ungültig wird?

In einem Testszenario konnte derartiges produziert werden. Bereits Änderungen an den Zeilenumbrüchen einer XML-Datei können eine binäre Signatur ungültig machen. Windows verwendet üblicherweise CR+LF, Linux dagegen LF. Eine solche Änderung konnte bei einem Test bei der Übertragung über die beBPo-Infrastruktur erzeugt werden. Deswegen hat der eNoVA-Editor eine Option, innerhalb der XML-Antwort keine Zeilenumbrüche zu verwenden.
