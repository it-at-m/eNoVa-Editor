Installationsanleitung

Diese Anleitung richtet sich an Administratorinnen und Administratoren, die den eNoVA-Editor für ihre Kommune bereitstellen möchten.

1. eNoVA-Editor herunterladen

Laden Sie die aktuelle Version des eNoVA-Editors von der GitHub-Releases-Seite herunter.

Zu den GitHub Releases

Laden Sie die Datei eNoVA-editor-<Version>.zip herunter.

2. Installation

Entpacken Sie die ZIP-Datei in das gewünschte Installationsverzeichnis. Bei Windows ist dies üblicherweise das neu zu erstellende Verzeichnis C:\Program Files\eNoVA-Editor

Die Verzeichnisstruktur darf dabei nicht verändert werden. 

eNoVA-editor/
├── app/
├── codelists/
├── Input.htm
├── Output.htm
├── sender-config.xml
├── caseworkers.xml
├── codelists.properties
├── answer-transform.xsl
└── eNoVA-editor.cmd

Eine separate Java-Installation ist nicht erforderlich. Die benötigte Java-Laufzeitumgebung ist Bestandteil des eNoVA-Editor-Pakets.

3. Absender konfigurieren

Öffnen Sie die Datei sender-config.xml.

Tragen Sie dort den Namen Ihrer Kommune bzw. Behörde ein.

Beispiel: 

<sender>
    <name>Gemeinde Musterstadt</name>
</sender>

Dieser Name wird vom eNoVA-Editor unter anderem bei der Erzeugung der XJustiz-Antwort verwendet.

4. Sachbearbeiter konfigurieren

Die im eNoVA-Editor auswählbaren Sachbearbeiterinnen und Sachbearbeiter werden in der Datei caseworkers.xml konfiguriert.

Die mitgelieferten Beispieldaten müssen durch die Daten der eigenen Organisation ersetzt werden.

Die dort hinterlegten Einträge werden beim Start der Anwendung geladen und stehen anschließend im Auswahlfeld für die Sachbearbeitung zur Verfügung.

5. Anpassbare Dateien

Folgende Dateien können bei Bedarf angepasst werden:

  • Input.htm – bestimmt die HTML-Darstellung der eingehenden XJustiz-Nachricht.
  • Output.htm – bestimmt die HTML-Darstellung der erzeugten XJustiz-Antwort.

Änderungen an diesen Dateien betreffen die Darstellung im Browser. Die eigentliche XJustiz-Antwort-XML wird dadurch nicht direkt definiert.

6. Technische Dateien

Die folgenden Dateien und Verzeichnisse gehören zur technischen Konfiguration bzw. Programmlogik und sollten normalerweise nicht verändert werden.

app/

Enthält die Anwendung, ihre benötigten Bibliotheken und die mitgelieferte Java-Laufzeitumgebung.

Dateien in diesem Verzeichnis sollten nicht manuell verändert, verschoben oder gelöscht werden.

codelists/

Enthält die XML-Dateien der vom eNoVA-Editor verwendeten XJustiz-Codelisten.

Verwendung: Codelisten übersetzen technische Codes in verständliche Bezeichnungen oder liefern die zulässigen Werte für Auswahlfelder.

Beispielsweise wird die Auswahl „Sachentscheidung“ aus einer Codelist dieses Verzeichnisses aufgebaut.

Auch bei der Darstellung einer XJustiz-Nachricht können technische Codes, beispielsweise Rollen- oder Telekommunikationsarten, mit Hilfe dieser Dateien in ihre Bezeichnungen aufgelöst werden.

Konfiguration: Welche konkrete Codelist-Datei für einen bestimmten Zweck verwendet wird, legt die Datei codelists.properties fest.

Die Dateien sollten nicht einzeln ersetzt oder verändert werden, ohne zu prüfen, ob Codelist-Version und Konfiguration weiterhin zusammenpassen.

codelists.properties

Diese Datei verbindet die im eNoVA-Editor verwendeten Codelist-Namen mit den dazugehörigen XML-Dateien im Verzeichnis codelists/.

Beispiel: sachentscheidung.file legt fest, welche Datei ENOVA.Sachentscheidung-*.xml für das Auswahlfeld „Sachentscheidung“ verwendet wird.

Zusätzlich beschreibt die Datei, wie die Codelist-XML-Dateien technisch aufgebaut sind. Dazu gehört beispielsweise, welche Spalte den technischen Code und welche Spalte die sichtbare Bezeichnung enthält.

Der Ablauf ist vereinfacht: 

codelists.properties
        ↓
legt die verwendete Codelist-Datei fest
        ↓
codelists/*.xml
        ↓
technischer Code → sichtbare Bezeichnung

Änderungen an codelists.properties können dazu führen, dass eine andere Codelist-Version oder eine nicht passende Datei verwendet wird. Änderungen sollten daher nur gezielt vorgenommen werden.

answer-transform.xsl

Diese Datei enthält die XSLT-Transformation zur Erzeugung der XJustiz-Antwort.

Verwendung: Beim Erzeugen einer Antwort übergibt der eNoVA-Editor die zuvor eingelesene XJustiz-XML zusammen mit den Eingaben aus der Anwendung an diese XSLT-Datei.

Dazu gehören aktuell unter anderem:

  • Aktenzeichen
  • ausgewählte Sachentscheidung
  • ausgewählte Sachbearbeiterin bzw. ausgewählter Sachbearbeiter
  • neu erzeugte Nachrichten-ID
  • Herstellerinformationen des eNoVA-Editors

Die XSLT-Datei legt anschließend fest, an welchen Stellen diese Werte in der erzeugten XJustiz-Antwort verwendet werden und welche Inhalte der ursprünglichen Nachricht übernommen oder verändert werden.

Der Ablauf ist vereinfacht: 

eingehende XJustiz-XML
        +
Benutzereingaben
        ↓
answer-transform.xsl
        ↓
XJustiz-Antwort-XML

Änderungen wirken sich direkt auf die erzeugte XJustiz-Antwort aus. Fehlerhafte Änderungen können dazu führen, dass falsche Inhalte erzeugt werden oder die Antwort nicht mehr dem erwarteten XJustiz-Format entspricht. Änderungen sollten daher nur mit entsprechenden XSLT- und XJustiz-Kenntnissen vorgenommen und anschließend getestet werden.

eNoVA-editor.cmd

Startet den eNoVA-Editor unter Windows.

Die Datei setzt beim Start das Installationsverzeichnis als Anwendungsverzeichnis und startet anschließend die mitgelieferte Java-Laufzeitumgebung aus dem Verzeichnis app/.

Die Datei sollte normalerweise nicht verändert werden.

7. Berechtigungen

Der eNoVA-Editor erzeugt die HTML-Ansichten und die Antwortdateien im selben Verzeichnis wie die geöffnete XML-Datei.

Für die normale Nutzung sind keine Schreibrechte auf das Installationsverzeichnis erforderlich. Schreibrechte dort werden nur benötigt, wenn Konfigurationsdateien wie sender-config.xml, caseworkers.xml, Input.htm oder Output.htm administrativ geändert werden sollen.

8. Anwendung starten

Starten Sie den eNoVA-Editor über: 

eNoVA-editor.cmd

Nach dem Start kann eine XJustiz-XML-Datei über die Anwendung geöffnet und verarbeitet werden.

Für einen ersten Test kann die Datei: xjustiz_nachricht_beispiel_ersuchenSachentscheidung_mehrfach.xml im Verfeichnis https://github.com/it-at-m/eNoVa-Editor/blob/main/demo-output/ verwendet werden.
